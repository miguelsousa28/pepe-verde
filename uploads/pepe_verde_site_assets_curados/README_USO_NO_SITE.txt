PEPE VERDE — ASSETS CURADOS PARA O WEBSITE

Este pack contém fotografias e referências visuais organizadas para usar no site da Pepe Verde.
A seleção inclui assets enviados pelo cliente e imagens públicas de fontes autorizadas pelo utilizador.

Estrutura:
01_logo — logo original e versões temporárias limpas.
02_menu_original — menus reais enviados pelo cliente, PT/EN.
03_espaco_interior_exterior — espaço, esplanada, interior e balcão.
04_comida — pizzas, antipasti, saladas, piadine/food shots.
05_equipa_staff — fotos com staff/equipa quando disponíveis.
06_ambiente_lifestyle — ambiente à mesa, clientes, partilha.
99_originais_fontes — originais descarregados das fontes públicas para rastreabilidade.

Notas críticas:
1. O logo original recebido está em baixa resolução. Para produção final, pedir SVG/PDF/AI ou PNG transparente em alta resolução.
2. Algumas imagens públicas vêm de colagens e foram cortadas para ficarem mais úteis no site. Não são ideais para hero principal se houver alternativa profissional em alta resolução.
3. Não encontrei fotografias fortes e dedicadas de funcionários/equipa. Há apenas uma imagem de staff no balcão, com qualidade média.
4. Antes de publicar, validar com o cliente os direitos finais de uso e quais fotos podem mostrar clientes/pessoas.
5. Para hero, priorizar: espaco_interior_neon_mesas.jpg, comida_pizza_closeup_manjericao.jpg, comida_uber_eats_pepe_verde_spread.png, se a resolução funcionar bem.

Ver o ficheiro 00_manifesto_assets.csv para fonte, categoria e uso recomendado de cada asset.
